📡 POST /send (or /api/send)

Send an email through the relay service by sending a JSON HTTP POST request with your client application's X-API-KEY header.

curl -X POST https://email-api.yourdomain.ph/send \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: solutions_key_789" \
  -d '{
    "app": "solutions-portfolio",
    "to": "derf@sanchez.ph",
    "subject": "New Licensing Inquiry",
    "replyTo": "client@example.com",
    "html": "
Quote Request
Message details...
",
    "text": "Quote Request: Message details..."
  }'
📦 Payload Specification

The request body must be valid JSON containing at least one of html or text.

{
  "app": "solutions-portfolio",     // (Required) Calling application identifier
  "to": "client@example.com",       // (Required) Valid recipient email address
  "subject": "Email Subject",       // (Required) Subject line
  "replyTo": "sales@domain.ph",     // (Optional) Reply-To address
  "html": "<h1>Hello</h1>",         // (Optional*) HTML email body
  "text": "Hello text version"      // (Optional*) Plain-text fallback
}
